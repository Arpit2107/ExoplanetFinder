# Exoplanet Finder

A two-view 1D CNN that classifies Kepler DR24 Threshold Crossing Events (TCEs) as planet candidates (PC) or astrophysical/non-transiting false positives (AFP/NTP), using global (2001-bin) and local (201-bin) views of phased light curves. A gradient-boosting baseline on period, duration, and depth provides a minimal-feature comparison.

## Problem and Data

**Source:** NASA Exoplanet Archive Q1–Q17 DR24 TCE table + per-star Kepler long-cadence light curves via `lightkurve`. This repo uses a **5,000-TCE subset** (1 TCE per star) of the full 15,737 DR24 TCEs.

**Labels:** `av_training_set` in {PC, AFP, NTP}
- PC (planet candidate) → **1,529** (30.6%)
- AFP (astrophysical false positive) → **1,691** (33.8%)
- NTP (non-transiting phenomenon) → **1,780** (35.6%)

**Planet fraction:** ~30.6% in this subset vs ~23% in the full DR24 table.

**Splits (GroupShuffleSplit by `kepid`, seed 42):**
- Train: **3,106** (AFP: 1,052 | NTP: 1,098 | PC: 956)
- Val: **932** (AFP: 325 | NTP: 327 | PC: 280)
- Test: **962** (AFP: 314 | NTP: 355 | PC: 293)

**Hard rules followed:**
- Never use `av_pred_class` or any `av_pp_*` columns (they are another model's predictions).
- Split by `kepid` (GroupShuffleSplit), never by row. 80/10/10 train/val/test. Seed 42.
- Units: `tce_duration` in HOURS; `tce_period` and `tce_time0bk` in DAYS (BKJD).
- Mask transits BEFORE flattening.
- Metrics: AUC + precision/recall for the planet class. Never report accuracy.
- Cache RAW stitched light curves per star (not flattened; flattening depends on each TCE).
- Fix seeds for random, numpy, torch.

## Pipeline (text diagram)

```
DR24 TCE CSV (5,000 rows)
         │
         ▼
prepare_labels.py  ──►  data/processed/tce_labeled.parquet  (with split column)
         │
         ▼
download.py  ──►  data/lightcurves/{kepid}.npz  (raw stitched time, flux, flux_err)
         │
         ▼
build_dataset.py  ──►  data/processed/views.npz
         │              global:  (5000, 2001)  ← phased, binned, normalized
         │              local:   (5000, 201)   ← 0.25× period window
         │              label:   (5000,)
         │              tce_id:  (5000,)
         │
         ├──────────────────────┬──────────────────────┐
         ▼                      ▼                      ▼
baseline.py            train.py               evaluate.py
(GB on period,         (Two-view 1D CNN)       (Test eval: AUC, PR,
 duration, depth)                            ROC, error analysis)
         │                      │                      │
         └──────────────────────┴──────────────────────┘
                              │
                              ▼
                      results/metrics.csv
                      results/plots/*.png
                      results/test_summary.md
```

**CNN Architecture (~172K parameters):**
- Global branch: 1×2001 → 3×ConvBlock(16→32→64, k=5, pool=5×2) → 1024-d
- Local branch: 1×201 → 2×ConvBlock(16→32, k=5, pool=7×2) → 128-d
- Fusion: 1152 → 128 → 64 → 1 (sigmoid)

## Error Analysis

- **False positives (AFP/NTP predicted as planet):** 50 cases saved to `dashboard/data/test_false_positives.npz` (top 20 by probability plotted). Many show secondary-eclipse signatures at phase ±0.5, suggesting eclipsing binaries fool the model.
- **False negatives (PC predicted as not-planet):** 50 cases saved to `dashboard/data/test_false_negatives.npz` (top 20 by lowest probability plotted). Often shallow, long-period transits with low SNR.
- **Likely label errors (confident-wrong — suspicions, not facts):**
  - Confident FPs (prob > 0.9, label=0): **0 cases** in current run
  - Confident FNs (prob < 0.1, label=1): **0 cases** in current run
  - Top 10 FPs (prob 0.56–0.58) and top 10 FNs (prob 0.05–0.34) saved to `dashboard/data/test_flagged_label_errors.npz` (20 total) for manual review.

## How to Reproduce

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Place DR24 TCE CSV at data/raw/dr24_tce.csv
#    (Download from NASA Exoplanet Archive: Q1-Q17 DR24 TCE table)

# 3. Prepare labels and splits
python src/prepare_labels.py

# 4. Download light curves for all stars in splits (~5000 stars)
#    Start with a limit for testing, then run without --limit
python src/download.py --limit 200
python src/download.py  # full run, resumable

# 5. Build global/local views
python src/build_dataset.py

# 6. Train gradient boosting baseline (tunes on val)
python src/baseline.py --run-name gb_baseline

# 7. Train two-view CNN (early stopping on val AUC)
python src/train.py --run-name cnn_run1

# 8. Evaluate ONCE on test set
python src/evaluate.py

# 9. Demo plots
python src/demo.py compare
python src/demo.py kepler90
```

**Dashboard:**
```bash
cd dashboard
npm install
npm run dev     # frontend at localhost:5173
# In another terminal:
npm run backend # backend at localhost:8000
```

## Limitations

- **5,000-TCE subset** (1 per star) of the full 15,737 DR24 TCEs.
- **Planet fraction ~30.6%** in this subset vs ~23% in the full table — class balance differs from production.
- **Smaller model (~172K params)** than Shallue & Vanderburg (2018) who achieved 0.988 AUC with a larger Inception-style architecture on the full DR24 dataset.
- **Label noise:** DR24 `av_training_set` labels are human-vetted but not perfect; confident-wrong analysis suggests possible label errors but none reached high-confidence thresholds (prob > 0.9 or < 0.1) in this run.
- **No extensive hyperparameter search:** Only learning_rate and max_depth tuned on validation for baseline; CNN uses fixed architecture and dropout=0.3.
- **No test-time augmentation or ensembling.**
- **Single-star demo (Kepler-90):** Probabilities shown are illustrative only, not evidence of generalization.
- **Metrics files not yet generated:** `results/metrics.csv`, `results/test_summary.md`, `dashboard/data/metrics.json` will be created by `evaluate.py`.

## What I'd Do Next

1. Scale to full DR24 dataset (all ~15k TCEs, ~6k unique stars).
2. Increase model capacity (wider channels, deeper branches) to approach S&V 2018 performance.
3. Add test-time augmentation (phase jitter, horizontal flip) and ensemble multiple seeds.
4. Investigate label correction via confident-wrong analysis (semi-supervised relabeling).
5. Try focal loss or class-balanced sampling to improve recall on rare planet class.
6. Add stellar parameters (Teff, logg, radius) as auxiliary inputs to the fusion layer.
7. Cross-match with DR25/Kepler-1627 catalog for external validation.
